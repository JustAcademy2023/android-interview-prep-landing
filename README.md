# Android Developer Interview Questions

A fun, responsive landing page with flip-card Android interview questions for freshers and experienced developers, plus links to Android, iOS, Flutter and React Native courses and career blogs.

## Features

- Flip-card question deck with Fresher and Experienced filters
- Sticky header, card layouts and a full footer, all responsive
- Every course and blog link is clickable
- Plain HTML and CSS with a little JavaScript, no build step
- Keyboard friendly and respects reduced motion

## Run locally

Open `index.html` in any browser.

## Deploy with GitHub Pages

1. Push `index.html` and `README.md` to the repository root.
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. Save, and your site goes live in a minute.
